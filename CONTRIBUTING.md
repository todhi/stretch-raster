# Contributing to Stretch

Thank you for considering contributing to Stretch!

## How to Contribute

1. **Fork the Repository**: Create your own branch from `main`.
2. **Make Improvements**:
   - Write clear, concise code adhering to PEP 8 standards.
   - Maintain compatibility across major geospatial formats (GeoTIFF, Erdas Imagine, etc.).
   - Ensure multi-threading and GUI responsiveness remain unblocked.
3. **Submit a Pull Request**: Provide a descriptive summary of your changes and any relevant test results.

## Reporting Issues

If you find a bug or have a feature request:
- Check existing issues to see if it has already been reported.
- Open a new issue with a clear description, system information (OS, Python version), and sample raster metadata if possible.
